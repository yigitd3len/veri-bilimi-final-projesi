## Projeyi Çalıştırma Talimatları

### 1. Gerekli Kütüphaneleri Kur
```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

### 2. Veri Setini İndir
Kaggle'dan `results.csv` dosyasını indirip `spor_analitigi_proje.ipynb` ile **aynı klasöre** koy:
- https://www.kaggle.com/datasets/martj42/international-football-results-from-1872-to-2017

### 3. Notebook'u Çalıştır
- **Jupyter Notebook:** Dosyayı aç → `Cell > Run All`
- **VS Code:** Dosyayı aç → `Run All` butonuna bas
- **Google Colab:** Dosyayı yükle → `Runtime > Run All`
